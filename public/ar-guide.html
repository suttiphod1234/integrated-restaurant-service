คู่มือการตั้งค่า AR สำหรับคุณครู

ทำตาม 3 ขั้นตอนด้านล่างเพื่อเริ่มใช้งานระบบจำลองบนมือถือ

1. อัปโหลดไฟล์

นำไฟล์ Restaurant_Immersive_AR_Simulator.html ไปอัปโหลดบนเว็บโฮสติ้งที่เป็น HTTPS เช่น GitHub Pages หรือ Vercel

2. สร้าง QR Code

เมื่อได้ลิงก์ (URL) มาแล้ว ให้นำมาสร้าง QR Code เพื่อให้นักเรียนสแกนเปิดแอปพลิเคชันบนมือถือ

3. สแกน Marker

เปิดแอปบนมือถือ ส่องกล้องไปที่ Hiro Marker (รูปด้านล่าง) เพื่อให้ลูกค้า 3D ปรากฏตัว
